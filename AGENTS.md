# For agents working on Tokuly

Read this first, then `CLAUDE.md`. Everything you need to continue the work is in the repository; nothing
depends on a past session.

- **What is decided**: [`docs/agents/rules.md`](docs/agents/rules.md) — the product owner's decisions. Binding.
- **How work flows**: [`docs/agents/process.md`](docs/agents/process.md) — issues, delegation, review, merging.
- **Working with the other agent**: [`docs/collaboration.md`](docs/collaboration.md) — labels, Draft PRs, granularity.
- **Reviewing**: [`docs/agents/review.md`](docs/agents/review.md); backend PRs also
  [`docs/agents/backend-checklist.md`](docs/agents/backend-checklist.md).
- **The machine**: [`docs/agents/machine.md`](docs/agents/machine.md) — setting up and recovering a dev box.
- **Tools**: `tools/agent/` (machine scripts in `tools/agent/machine/`) and the `tokuly-ops` skill (`.claude/skills/tokuly-ops`).
- **What to do next**: open issues by priority label (`gh issue list --label priority:high`), and the parent
  issues with sub-issues (e.g. #28 for the mobile app).

The owner writes in Japanese and expects replies in Japanese. The repository is public.
