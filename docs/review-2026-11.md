## 確認して問題がなかったもの

- **ドメイン境界**：依存していないドメインのテーブルを読む・書く SQL は 0 件（`users` の読み取りという明文化された例外のみ）。
- **CSRF**：セッションは `Authorization: Bearer` のみ。Cookie はリフレッシュ専用（`HttpOnly; SameSite=Lax`、パスは `AuthService` のみ）。
- **外向き通信**：利用者由来の URL はすべて `tokuly_core::egress` 経由。ガードを通らないクライアントは運用者が設定した URL だけを呼ぶ。
- **アップロード**：公開バケットにはサーバーが生成したファイルだけが入り、元ファイルは非公開バケットから `attachment` で配られる。
- **公開ポート**：認証なしの Valkey・NATS は公開されず、Mailpit と Grafana は `127.0.0.1` のみ。
- リアルタイム基盤（ルート単位の購読、プレゼンス、購読の取り消し）とリフレッシュトークンの再利用検知は設計どおり。
