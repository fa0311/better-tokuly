# Data bundled with tokuly-geo

These files are compiled into the crate (`include_bytes!`) so reverse
geocoding, time zones and footprint regions work offline, with no external
service. They are generated by `build.sh` (which downloads the sources and
runs `build_data.py`); the outputs are checked in, so the script only needs to
run to refresh them.

| File | Contents | Source |
|---|---|---|
| `regions.ndjson.gz` | 240 countries and 4,488 first-level subdivisions (prefectures, states, provinces) as GeoJSON geometries, one JSON object per line: `id`, `kind`, `name`, `name_ja`, `cc`, `gn`, `geometry` | Natural Earth 1:10m Cultural Vectors, `ne_10m_admin_0_countries` and `ne_10m_admin_1_states_provinces`, release v5.1.2 |
| `gazetteer.tsv.gz` | 233,079 populated places: `lat`, `lng`, country code, GeoNames admin1 code, name, Japanese name, population, municipality (English), municipality (Japanese) | GeoNames `cities500` (places with 1,000+ inhabitants and administrative seats; city sections left out), and every named populated place of the `JP` country extract |
| `admin1.tsv.gz` | First-level subdivision names by GeoNames key (`JP.40` → Tokyo / 東京都) | GeoNames `admin1CodesASCII.txt`, Japanese names from GeoNames alternate names (Natural Earth `name_ja` as a fallback) |
| `countries.tsv` | Country names by ISO 3166-1 alpha-2 code | GeoNames `countryInfo.txt`, Japanese names from Natural Earth `NAME_JA` (GeoNames alternate names as a fallback) |

Downloaded 2026-11-21 from:

- <https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson>
- <https://download.geonames.org/export/dump/> (`cities500.zip`, `JP.zip`,
  `alternatenames/JP.zip`, `alternateNamesV2.zip`, `admin1CodesASCII.txt`,
  `countryInfo.txt`)

## What was done to the sources

**Boundaries.** Simplified with [mapshaper](https://github.com/mbloch/mapshaper)
0.6.102 (`-simplify weighted 20% keep-shapes`, coordinates rounded to 0.001°,
about 100 m), then dissolved so that each ISO code is one feature. Region IDs
are the ISO 3166-1 alpha-2 code for countries (Natural Earth's `ADM0_A3` where
it has no ISO code) and the ISO 3166-2 code for subdivisions (Natural Earth's
`adm1_code`, e.g. `PHL-2187`, where it has no well-formed one). Areas of
indeterminate sovereignty and leased bases are left out. Region areas are
computed by PostGIS from the simplified geometry when the data is seeded
(`Geo::seed_regions`).

Natural Earth's subdivisions follow each country's own first level, which is
finer than one might expect in a few countries (for example counties and
districts in the United Kingdom, municipalities in Slovenia).

**Gazetteer.** Japanese place names come from the language-tagged GeoNames
alternate names (`ja`, preferring the entry marked as preferred, then names
written in kanji). In Japan every place is resolved to its municipality
through the GeoNames admin codes: the `ADM2` entry (市・区・郡) and, where
present, the `ADM3` entry found by its JIS code — a ward of a designated city
(「大阪市北区」) or a town or village of a district (「奥多摩町」). That is where
names like 「渋谷区」 come from.
